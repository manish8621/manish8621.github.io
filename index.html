// flagship● in design

Bike Tamper Detection System

A low-power theft alarm for a motorcycle. An accelerometer wakes the ESP32 from deep sleep on movement, it decides whether it's a real tamper, and pushes an alert over MQTT to my home server — with a BLE link to an Android companion app for arming, status and config.

  • Interrupt-driven wake: MPU6050 motion IRQ → ESP32 deep-sleep exit
  • Structured FreeRTOS tasks for sensing, connectivity and alerting
  • Robust BLE: reconnection, bonding, and state sync with the app
  • Single 18650 cell with TP4056 charging, designed around battery life
